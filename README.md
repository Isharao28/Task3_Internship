# Task 3 - Linear Regression on Spotify Dataset

## Objective

To build and evaluate a Linear Regression model for predicting song popularity using audio features from a Spotify dataset.

## Tools Used

* Google Colab
* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Dataset

Spotify Tracks Dataset from Kaggle

## Steps Performed

1. Imported and explored the dataset
2. Selected relevant features and target variable
3. Handled missing values
4. Split the dataset into training and testing sets
5. Trained a Linear Regression model
6. Made predictions on test data
7. Evaluated model performance using MAE, MSE, and R² Score
8. Visualized actual vs predicted values
9. Analyzed feature coefficients

## Results

The Linear Regression model was used to predict song popularity based on various audio characteristics. Model performance was evaluated using standard regression metrics, and feature coefficients were analyzed to understand the impact of each feature on popularity.

## Conclusion

This project demonstrates the implementation of Linear Regression using Scikit-learn and provides insights into how audio features influence song popularity.
